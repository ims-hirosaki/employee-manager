# 01 システム概要

- 対象: WordPressプラグイン「社員情報管理システム」 v1.2.1
- 読者: 全員（利用者・管理者・エンジニア）

---

## 1. 目的

社員の**基本情報・所属・保険・学歴・職歴・資格・扶養者・乗組員コード**をWordPress管理画面で一元管理する。
他のプラグイン（勤怠管理など）が社員情報を参照できるよう、**公開API関数**も提供する。 [コード確認]

## 2. 主な機能 [コード確認]

| 機能 | 概要 |
|---|---|
| 社員一覧 | キーワード検索、所属/部署/在籍状況での絞り込み、並べ替え、ページング(20/50/100件)、在籍⇔退職の切替、複数選択の一括切替、統計カード（在籍人数・所属別人数） |
| 社員登録・編集 | 5ステップのフォーム。社員コードと氏名が必須、他は任意 |
| 乗組員コード履歴 | 乗組員コードを適用期間つきの履歴で管理（コード変更しても過去が追える） |
| マスタ管理 | 所属・部署・役職・職種の登録・改名・有効/無効・表示順・削除 |
| CSV出力 | 出力項目の選択、列順のドラッグ調整、テンプレート保存（ユーザーごと）、CSV/TSV、Shift-JIS/UTF-8、ヘッダ有無、絞り込み |
| CSVインポート | ①基本情報（保険・退職含む）②経歴・資格 ③扶養者 の3種。ひな形ダウンロード、プレビュー、重複時の動作選択 |
| 公開API | 在籍社員一覧、ID/社員コードでの取得、乗組員コード履歴、マスタ一覧 |

**ないもの（できないこと）** [コード確認]
- 社員の**削除機能（画面）**はない。退職扱い（在籍フラグOFF）で運用する。
- 変更履歴（誰がいつ何を変更したか）の記録はない（乗組員コード履歴の作成者/更新者IDを除く）。
- 乗組員コード履歴の**削除**はできない（追加・期間修正のみ）。
- 社員の写真・添付ファイルの管理機能はない。
- マイナンバーの暗号化処理はない（カラムはある）。

## 3. 動作要件 [コード確認／README]

| 項目 | 要件 |
|---|---|
| WordPress | 5.8 以上（READMEの記載） |
| PHP | 8.0 以上（README記載。コード内で `fn` アロー関数・`??` を使用） |
| DB | MySQL 5.7+ / MariaDB 10.3+（README記載） |
| フロント | jQuery（WordPress同梱）のみ。外部ライブラリなし |
| 権限 | カスタム権限 `access_custom_plugins` 等（`08` 参照）。以前は `manage_options` |

## 4. 技術構成 [コード確認]

- 実装言語: PHP（WordPressプラグイン）／JavaScript（jQuery）／CSS
- 画面はサーバー側PHPで枠を描画し、データの読み書きは **admin-ajax.php への AJAX（jQuery）** で行う。
- CSV出力のみ、非表示フォームのPOST送信でファイルをダウンロードする。
- テーブルは `dbDelta()` で作成・更新。プラグイン有効化時、およびバージョン不一致を検知したとき（`plugins_loaded` 時）に自動実行。
- テーブル接頭辞は WordPress の `$wpdb->prefix`（通常 `wp_`）。本仕様書では `{prefix}` と表記。

## 5. 全体構成図

```
[ブラウザ（管理画面）]
   │ 画面表示（PHPビュー）       admin/views/*.php
   │ 操作・保存（AJAX / jQuery） admin/assets/admin.js
   ▼
[admin-ajax.php] ─ nonce検証＋権限検証 ─▶ [EMP_* クラス]
                                          ├ EMP_Employee   社員CRUD・乗組員コード履歴・統計
                                          ├ EMP_Master     マスタCRUD
                                          ├ EMP_CSV_Export CSV出力・テンプレート
                                          └ EMP_CSV_Import CSVインポート
                                                 │
                                                 ▼
                                         [MySQL 13テーブル]（`04` 参照）

[他プラグイン（勤怠管理等）] ─ 公開API関数 emp_get_*() ─▶ EMP_Employee / EMP_Master
```

## 6. 用語集

| 用語 | 意味 |
|---|---|
| 社員コード（`employee_code`） | 人事が付ける社員の識別番号。**重複不可**。先頭ゼロ可（例: 0001）。文字列として扱う。 |
| 内部ID（`id`） | DBが自動採番する社員の不変ID。一覧では `#001` 形式で表示。他テーブルは `employee_id` でこれを参照。 |
| 乗組員コード（`crew_code`） | 乗務員（ドライバー等）を識別する別コード。乗務員でない社員は未設定（NULL）。**社員コードとは別**。 |
| 乗組員コード履歴 | 乗組員コードの使用期間（開始日・終了日）の記録。コードが変わっても過去の勤務データを同じ社員に紐づけるために使う。 |
| 現行コード | 現在使用中の乗組員コード（履歴の `is_current=1`、かつ社員マスタの `crew_code`）。 |
| 在籍フラグ（`is_active`） | 1=在籍中、0=退職。画面の「在籍状況」。**退職日とは連動しない**。 |
| 所属／部署／役職／職種 | 社員に紐づく4種のマスタ項目。 |
| 雇用区分 | 正社員／契約社員／パート・アルバイト の3択。 |
| 週勤務日数 | 1〜6の数値（週1勤務〜週6勤務）。 |
| 有効／無効（マスタ） | マスタ項目の状態（`is_active`）。使用中の項目は削除できないので、使わなくなったら無効にする。 |
| テンプレート（CSV出力） | CSV出力の項目と列順の組み合わせの保存。**WordPressユーザーごと**に保存される。 |
| ひな形 | CSVインポート用の見本ファイル（3種）。 |
| nonce | 画面ごとに発行される使い捨て風の確認キー（CSRF対策）。AJAXに付与される。 |
| capability（権限） | WordPressの機能別権限。本プラグインでは `access_custom_plugins`／`edit_custom_plugins`／`manage_custom_plugin_settings`。 |
| staging | 検証環境（`staging`ブランチ→検証サーバーへ自動デプロイ）。 |

## 7. 関連システム（このリポジトリ外） [リポジトリ外]

引き継ぎ書（`引き継ぎ書_2026-08-27.md`）によると、次の関連システムがある。**これらはこのリポジトリには含まれない。**

- **勤怠管理プラグイン（attendance-manager）**: 本プラグインの公開API（`emp_get_*`、乗組員コード履歴API）を使い、長距離勤怠を社員単位で集計する。社員は不変の内部ID（`employee_id`）で識別し、乗組員コードは対象期間に有効な全コードをまとめて扱う。
- **拘束時間インポーター（`import_kousoku.php`）**: 外部Excel「拘束時間管理表.xlsx」を読み込み、`wp_kousoku_log` に保存。本プラグインの `emp_crew_code_history` を `乗組員コード＋勤務日` で照合して社員に紐づける。未紐づけ行も原本として保存し警告扱いにする。

これらの挙動の詳細は、それぞれのシステムの資料を参照すること。本仕様書は本プラグイン単体の仕様を扱う。
