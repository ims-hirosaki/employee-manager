# 02 ユーザーマニュアル（やりたいこと別）

- 読者: 人事・総務などの利用者
- 前提: WordPress管理画面にログインし、左メニューに「**社員情報管理**」が表示されていること。
  表示されない場合は権限がありません（管理者に「社員情報管理の利用権限」を依頼）。権限の種類は `08` を参照。
- 用語は `01_システム概要.md` の用語集を参照。

---

## 0. メニューの全体像

左メニュー「社員情報管理」の下に5つの画面がある。

| メニュー | できること |
|---|---|
| 社員一覧 | 社員を探す、在籍/退職を切り替える、編集画面へ進む |
| 新規社員登録 | 社員を1人登録する（編集もこの画面） |
| マスタ管理 | 所属・部署・役職・職種の一覧を整える |
| CSV出力 | 社員情報をExcel等で使えるファイルに出す |
| CSVインポート | CSVファイルから社員情報をまとめて登録する |

---

## 1. 最初に行う準備：マスタを登録する

社員の所属・部署などは「マスタ」から選ぶ方式。**先にマスタを作っておく**と社員登録がスムーズ。

1. 「社員情報管理」→「**マスタ管理**」を開く。
2. 上のタブ（**所属／部署／役職／職種**）から種類を選ぶ。
3. 「**＋ 新規追加**」を押し、名称と表示順（数字）を入力して「**登録**」。
4. 表示順の小さい順に並ぶ（同じ数字ならID順）。

### マスタの変更・無効化・削除
- **名前を変える**: 行の「編集」を押すと名称欄が入力欄になる。書き換えて **Enter** で確定、**Esc** でキャンセル（入力欄から外れる操作でも確定される）。
- **有効／無効を切り替える**: 「状態」の表示（有効／無効）をクリック。
- **削除**: 行の「削除」→確認ダイアログで承認。
  - すでに社員に使われている項目は削除できない（「この項目は ○ 名の社員に使用されているため削除できません。先に社員情報を変更してください。」と表示）。
  - 使わなくなっただけなら削除せず**無効**にしておく。
- **絞り込み**: 各タブ上部の入力欄に名称の一部を入れると表示を絞れる。
- 注意: 無効にしても、本プラグインの社員登録画面・一覧の絞り込みの選択肢には**残る**（現在の実装）。CSVインポートの名称照合では**無効な項目は照合対象外**になる。

## 2. 社員を1人登録する

1. 「**新規社員登録**」を開く（または一覧の「＋ 新規社員登録」）。
2. 上部の数字（1〜5）で現在のステップがわかる。「次へ →」「← 前へ」で移動、数字のタブをクリックしても移動できる。
3. 各ステップを入力する。

| ステップ | 入力する内容 |
|---|---|
| 1 基本情報 | 社員コード・氏名（**必須**）／フリガナ／性別／血液型／生年月日／入社日／個人番号／在籍状況／所属・部署・役職・職種／雇用区分／週勤務日数／初回乗組員コード／住所・電話／緊急連絡先／備考 |
| 2 保険・退職 | 健康保険・厚生年金・雇用保険・労災保険の各「番号」と「取得日」／退職日 |
| 3 学歴・職歴・資格 | 「＋ 追加」で行を増やす。不要な行は右端の「✕」で削除 |
| 4 扶養者 | 「＋ 追加」で行を増やす（氏名・フリガナ・続柄・生年月日） |
| 5 確認 | 基本情報と所属・役職の入力内容を確認 |

4. 画面左下の「**登録する**」を押す。どのステップからでも押せる。
5. 「登録しました」と表示され、少しして社員一覧に戻り「社員情報を保存しました。」と出る。

### 入力のコツ・注意
- **必須は「社員コード」と「氏名」だけ。** 空のまま「次へ」や「登録する」を押すと、赤枠になり「必須項目を入力してください」と表示され、ステップ1に戻される。
- **社員コードは他の社員と重複できない。** 重複すると「この社員コードはすでに使用されています」と表示される。
- 社員コードは「0001」のように先頭が0でもよい。
- 日付は日付選択（カレンダー）で入力。
- **個人番号（マイナンバー）**は入力欄が伏せ字になる。12桁までの入力。**保存時に暗号化されると画面に書かれているが、実際には暗号化されていない**（`08`・`11` 参照）。取り扱いに注意し、必要がなければ入力しない運用も検討すること。
- **初回乗組員コード**は、乗務員でない人は空欄でよい。入力すると**登録した日が使用開始日**として自動記録される。
- 在籍状況のスイッチ: ON=在籍中、OFF=退職。**退職日を入れてもスイッチは自動では変わらない**ので、退職の場合は両方を設定する。
- ステップ5の確認画面には、基本情報と所属・役職の概要のみ表示される（保険・学歴・扶養者などは表示されない）。見落としがないよう各ステップで確認する。

## 3. 社員情報を探す・編集する

### 探す（社員一覧）
- 上部の検索欄に**氏名・フリガナ・社員コード**の一部を入力（入力が止まって少しすると自動で絞り込まれる）。
- 「すべての所属」「すべての部署」「在籍状況」のプルダウンで絞り込み（組み合わせ可）。
- 列見出しの「**社員コード／氏名／入社日**」をクリックすると並べ替え（もう一度で昇順⇔降順）。
- 画面下で表示件数（20／50／100件）とページを切り替える。
- 統計カード: 左上に**在籍中の人数**（カード名は「総社員数」だが表示されるのは在籍中の人数）、右に**所属ごとの在籍人数**。所属未設定の在籍者は「未所属」として出る。

### 編集する
1. 一覧の行の「**編集**」ボタンを押す（行そのものをクリックしても移動しない）。
2. 画面タイトルが「社員情報編集：○○」になる。登録時と同じ5ステップで変更し、「**更新する**」を押す。

### 在籍／退職を切り替える
- **1人だけ**: 一覧の「在籍状況」欄（在籍中／退職の表示）をクリックすると即座に切り替わる。
- **複数人まとめて**: 行頭のチェックボックスで選ぶと下に操作バーが出る。「一括：在籍に変更」「一括：退職に変更」。全選択はヘッダのチェックボックス。バーの「✕」で選択解除。
- 退職にしても情報は消えない。在籍に戻すこともできる。

### 注意
- **社員を完全に削除する機能は画面にない。** 退職扱いにして情報を残す運用。
- 学歴・職歴・資格・扶養者は、保存のたびに**画面上の内容で全部入れ替わる**。行を消して保存すると、その行はデータからも消える。
- 職歴の「備考」はこの画面には入力欄がない（CSVインポートでは入れられる）。**社員編集画面から保存すると、CSVで入れていた職歴の備考は消える**（`11` 参照）。

## 4. 乗組員コードを変更する（乗務員のみ）

乗組員コードが変わったときは、**過去のコードを残したまま**新コードに切り替える。

1. 一覧から該当社員の「編集」を開く。ステップ1の「所属・役職」カードに「**乗組員コード履歴**」が表示される。
2. 「新しい乗組員コード」欄に新コードを入力し、「**新規コードを追加**」を押す。
3. 「新しい乗組員コードを追加しました（使用開始日：YYYY-MM-DD）」と表示され、画面が再読み込みされる。

**どうなるか**
- **使用開始日は「追加した当日」**で自動設定される。
- それまでの現行コードは「過去」になり、**使用終了日は追加日の前日**になる。
- 履歴一覧に「現行」「過去」が表示される。

**できない・拒否されるケース**（メッセージは `05` に全一覧）
- すでに現行のコードと同じ。
- 他の社員が同じ期間に使っているコード。
- その社員の過去履歴にあるコードを再び使う（期間管理機能で調整が必要）。
- 現行コードの使用開始日と同じ日、またはそれ以前の日に追加しようとした。

**登録が遅れた場合（日付の修正）**
- 管理権限（`manage_custom_plugin_settings`）を持つ人だけが、履歴行の「使用開始日」「使用終了日」（と過去行のコード）を修正して「**期間を保存**」できる。
- 現行コード自体と、現行行の使用終了日は変更できない。
- 期間が重なる、開始日が終了日より後になる、といった設定は拒否される。
- 履歴の**削除**はできない。

> 既存社員の乗組員コードは、**CSVインポートや通常の保存では変更されない**。必ずこの「新規コードを追加」を使う。

## 5. CSVでデータを出力する

用途例: Excelで集計、他システムへの受け渡し。

画面は「CSV出力」。左で**何を出すか**、右で**どう出すか**を決める。

1. （任意）**STEP 0 保存済みテンプレート**: 過去に保存した組み合わせのカードをクリックすると、その項目・列順が再現される。
2. **STEP 1 プリセット**: 「基本情報のみ／人事用／保険情報／連絡先／すべて選択／クリア」から選ぶと項目が一括で選ばれる。
3. **STEP 2 出力項目**: 項目（チェック欄）をクリックして個別に追加・解除。各グループの「一括切替」でグループ単位のON/OFF。
4. **STEP 3 並び順**: 選んだ項目が一覧になる。ドラッグで順序を変更、「✕」で除外。**この順番がCSVの列順**になる。
5. 右側「**絞り込み条件**」: 在籍状況、所属、部署、入社日の期間。
6. 右側「**出力設定**」:
   - ファイル形式: CSV または TSV（タブ区切り）
   - 文字コード: **Shift-JIS**（Excelでそのまま開く場合の標準）／UTF-8（BOM付き）
   - ヘッダー行: あり／なし
   - ファイル名: 拡張子なしで入力（既定「社員情報_出力」）
7. 「出力サマリー」で列数と形式を確認し、「**CSV出力を実行**」を押すとファイルがダウンロードされる。

### テンプレートの保存・管理
- 項目と列順を決めたあと「**＋ 現在の選択を保存**」→ 名前（30文字まで）を入力→「保存する」。
- カードの「✏」で名前変更、「✕」で削除（確認あり）。
- テンプレートは**ログインしているユーザー本人のもの**だけが見える。他の人とは共有されない。

### 出力できない場合
- 項目を1つも選んでいない → 「出力する項目を1つ以上選択してください。」
- 条件に合う社員がいない → 「指定された条件に一致する社員がありません。絞り込み条件を確認してください。」
- 入社日が不正、または開始日が終了日より後 → 日付に関するエラー
- いずれも別画面（エラーページ）で表示される。ブラウザの戻るで画面に戻る。

### 出力ファイルのポイント
- 出力の並びは社員コード順。
- 「在籍区分」は「在籍中」または「退職」の文字で出る。
- 値が `=` `+` `-` `@` で始まる場合、Excelで式として動かないよう、先頭に `'`（アポストロフィ）が付く。
- 出力できる項目の一覧は `06` を参照。マイナンバー・雇用区分・週勤務日数・退職日・学歴/職歴/資格/扶養者は出力項目に**含まれない**。

## 6. CSVからまとめて登録する（インポート）

初回の一括移行や、年度更新などに使う。**3種類**のCSVがあり、**必ず①を最初に**行う。

| 種類 | 内容 | 注意 |
|---|---|---|
| ① 基本情報 | 社員の基本情報・住所連絡先・緊急連絡先・保険・退職日 | 先に実行する |
| ② 経歴・資格 | 学歴・職歴・資格（種別列で区別） | ①で作った社員コードに紐づく。**追記のみ** |
| ③ 扶養者 | 扶養者（1社員に複数行可） | ①で作った社員コードに紐づく。**追記のみ** |

### 手順
1. 「CSVインポート」を開き、上部のタブ（①②③）を選ぶ。
2. 「**ひな形をダウンロード**」で見本ファイルを入手する。
   - 2行目はサンプル。`#` で始まる行は読み込まれないので、削除してもそのままでもよい。
3. Excelで入力し、「**CSV UTF-8（コンマ区切り）**」で保存する。
   - **列の順番を変えない・列を削除しない**（列は見出しではなく**位置**で読み取られる）。1行目は見出し行として必ず読み飛ばされる。
   - 社員コードの先頭のゼロ（例: 0001）がExcelで消えないよう、列を文字列形式にしてから入力する。
4. 画面でCSVを**ドラッグ&ドロップ**、または「ファイルを選択」。
   - 文字コード: 「自動 / UTF-8」（既定）または「Shift-JIS」。**文字化けする場合は Shift-JIS に変えて**から選び直す。
5. 「**重複社員コードの処理**」を選ぶ（①のみ有効）。
   - **スキップ（既存を保持）**: すでにある社員コードの行は何もしない。
   - **上書き更新**: すでにある社員コードの行をCSVの内容で更新する。
6. 「**プレビューを確認する**」で内容を確認（エラー行は赤く表示）。
7. 「**インポートを実行する**」。結果（新規登録／上書き更新／スキップ／エラー件数、エラー詳細）が表示される。

### 重要な動作
- **①「上書き更新」**: CSVで空欄の項目も**空で上書き**される（既存の値が消える）。ただし以下は別扱い。
  - **乗組員コード**は上書きされない（CSVの値が現行と異なる場合、その行にエラーが出て既存コードが維持される。他の項目は更新される）。
  - **退職日**は、CSVに値がある場合のみ更新（空欄で消去はされない）。
- **①で新規登録の乗組員コード**: すでに他の社員や履歴で使われているコードは空欄で登録される（エラーに表示）。
- **所属・部署・役職・職種**は名称で照合（大文字小文字区別なし）。マスタにない名称は**エラーに出るが、その項目を空にして登録は続行**される。
- **②③は常に追記**。**同じファイルを2回取り込むとデータが重複する。**
- ②で社員コードが存在しない行、種別が「学歴」「職歴」「資格」以外の行は、その行だけエラーになる（他の行は取り込まれる）。
- 日付は `2020-01-01`／`2020/01/01`／`2020-1-1`／`2020/1/1` が使える。読み取れない日付は**エラーにならず空欄扱い**になる。
- 性別・雇用区分・週勤務日数などの**値の正しさはチェックされない**（ひな形の説明に従って入力する）。
- 件数が多いファイルは、サーバー設定により一部しか届かない可能性がある（`10` 参照）。取り込み後は一覧で件数を確認する。

詳しい列定義は `06_CSV出力・インポート仕様.md`。
