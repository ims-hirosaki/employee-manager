# 03 画面仕様

- 読者: 利用者・エンジニア
- すべての画面は WordPress 管理画面内（`admin.php?page=...`）。画面描画は `admin/views/*.php`、動作は `admin/assets/admin.js`。
- 各画面の最上位要素は `.wrap.emp-wrap`（CSSは `.emp-wrap` 配下にスコープ）。
- 画面アクセスに必要な権限: `access_custom_plugins`（なければ「権限がありません。」403）。

## 画面一覧

| 画面 | page パラメータ | ビュー | 起点メソッド |
|---|---|---|---|
| 社員一覧 | `employee-manager` | `employee-list.php` | `EMP_Admin_Menu::page_employee_list` |
| 新規社員登録／社員編集 | `employee-manager-new`（編集は `&id=社員ID`） | `employee-form.php` | `page_employee_form` |
| マスタ管理 | `employee-manager-master` | `master.php` | `page_master` |
| CSV出力 | `employee-manager-csv` | `csv.php` | `page_csv` |
| CSVインポート | `employee-manager-import` | `employee-import.php` | `page_import` |

メニューは WordPress の左メニュー（アイコン `dashicons-groups`、位置30）。「社員一覧」はトップメニューと同じページ。 [コード確認]

## 1. 社員一覧（`#emp-list-page`）

### レイアウト
1. タイトル「社員一覧」＋「＋ 新規社員登録」ボタン。保存直後（`emp_saved=1`）は緑の通知「社員情報を保存しました。」。
2. 統計カード:
   - 「総社員数」カード（`#statActiveTotal`）: **実際は在籍中の人数**（`active_total`）を「N名」と表示。全社員数（退職含む）は `total` として返るが画面には出していない。
   - 所属別カード（`#empAffilStatsRow`）: 有効な所属マスタごとの在籍人数。所属未設定の在籍者がいれば「未所属」を追加。
3. ツールバー: 検索欄、所属プルダウン、部署プルダウン、在籍状況プルダウン（すべて／在籍中のみ／退職のみ）、右端に「CSV出力」リンク。
4. テーブル「社員リスト」＋件数表示。
5. フッター: 「全 N 件中 a–b 件表示」、件数セレクト（20/50/100）、ページネーション。
6. 一括操作バー（1件以上選択時のみ表示）。

### 列
チェックボックス｜ID（`#001` 形式）｜社員コード（並べ替え可）｜氏名＋フリガナ（氏名で並べ替え可）｜所属｜部署｜役職｜入社日（並べ替え可）｜在籍状況（クリックで切替）｜操作（編集）。
値が無い所属/部署/役職/入社日は「—」。

### 動作 [コード確認]
| 操作 | 動作 |
|---|---|
| 検索欄入力／プルダウン変更 | 350ms の間隔で `emp_employee_get_list` を呼び、1ページ目から再表示 |
| 検索条件 | 氏名・フリガナ・社員コードの部分一致（OR）。所属・部署・在籍は完全一致（AND） |
| 並べ替え | 既定は社員コード昇順。同じ列を再クリックで昇順⇔降順 |
| 在籍状況のクリック | `emp_employee_toggle` を即時実行。成功で統計・一覧を再読込（確認ダイアログなし） |
| 編集ボタン | `admin.php?page=employee-manager-new&id={id}` へ遷移 |
| チェック選択 | 選択IDを保持（ページを移動しても保持）。1件以上で下部に「N 件選択中」バー |
| 一括：在籍／退職に変更 | 選択した社員ごとに `emp_employee_toggle` を1件ずつ送信。全件完了後に「N件を変更しました」 |
| 並べ替えキー | `employee_code`, `name`, `hire_date`（サーバー許可: + `id`）。数値として解釈できる値は数値順（`CAST(... AS UNSIGNED)` → 次に文字列順） |

### 注意
- 一覧の編集権限がない（`edit_custom_plugins` なし）ユーザーにも在籍切替やチェックボックスは表示される。操作するとサーバーが拒否する（`08` 参照）。
- 統計カードは検索条件とは無関係の全体集計。

## 2. 新規社員登録／社員編集（`#emp-form-page`）

### 共通
- タイトル: 新規は「新規社員登録」、編集は「社員情報編集：{氏名}」。「← 社員一覧に戻る」リンク。
- 編集時は `get_by_id()` で取得した社員データ（保険・退職・学歴・職歴・資格・扶養者・乗組員コード履歴を含む）が、HTML属性 `data-emp-json` 経由でJSに渡され、フォームに復元される。
- ステップインジケーター（1〜5）と進捗バー（20%刻み）。タブクリックでジャンプ可。**先のステップへ進むときは現在ステップを検証**（ステップ1のみ検証あり）。
- ボタン: 左に「登録する／更新する」（常時表示）、右に「← 前へ」「次へ →」。
- 送信時にステップ1の必須チェックに失敗したらステップ1へ戻る。送信中ボタンは「保存中...」。成功後 1.2秒で一覧（`emp_saved=1`）へ。

### STEP 1 基本情報
カード「社員マスタ基本情報」:
| 項目 | name | 種別・選択肢 | 必須 |
|---|---|---|---|
| 社員コード | `employee_code` | テキスト（例: 0001）。DB上限20文字 | ★必須 |
| 氏名 | `name` | テキスト。DB上限100 | ★必須 |
| フリガナ | `name_kana` | テキスト | |
| 性別 | `gender` | 選択なし／男性／女性／その他 | |
| 血液型 | `blood_type` | 選択なし／A／B／O／AB | |
| 生年月日 | `birthdate` | 日付 | |
| 入社日 | `hire_date` | 日付 | |
| 個人番号（マイナンバー） | `my_number` | パスワード型、最大12文字、「半角数値12桁」。ヒント「保存時は暗号化されます」（**実際は暗号化されない**） | |
| 在籍状況 | `is_active` | トグル（既定ON=在籍中。表示は「在籍中／退職」） | |

カード「所属・役職」:
| 項目 | name | 選択肢 |
|---|---|---|
| 所属・部署・役職・職種 | `affiliation_id` `department_id` `position_id` `job_type_id` | マスタの全項目（無効含む）＋「選択なし」 |
| 雇用区分 | `employment_type` | 選択なし／正社員／契約社員／パート・アルバイト |
| 週勤務日数 | `weekly_work_days` | 選択なし／週1勤務〜週6勤務（値1〜6） |
| 初回乗組員コード（**新規のみ**） | `crew_code` | テキスト。ヒント「登録日を使用開始日として自動保存します」 |
| 乗組員コード履歴（**編集のみ**） | — | 履歴行の一覧＋「新しい乗組員コード」入力＋「新規コードを追加」ボタン |

乗組員コード履歴の表示（編集時）:
- 各行: コード｜使用開始日｜使用終了日｜状態（現行／過去）｜「期間を保存」ボタン（管理権限者のみ）。
- 管理権限（`manage_custom_plugin_settings`）がない人: すべて読み取り専用でボタンも出ない。
- 管理権限がある人: 過去行はコード・開始日・終了日を編集可。**現行行はコードと終了日が編集不可**（開始日のみ編集可）。
- ヒント文:「追加日を使用開始日として自動保存し、現行コードは前日までの履歴になります。」管理権限者にはさらに「登録が遅れた場合は、履歴の日付を修正して『期間を保存』してください。」
- 「新規コードを追加」成功時と「期間を保存」成功時は、トースト表示後に**ページ再読込**。
- 履歴が空なら「履歴はまだありません」。

カード「住所・連絡先」: 郵便番号（`zip`、最大8文字）／住所（`address`）／自宅電話／携帯電話／会社携帯（`tel_home` `tel_mobile` `tel_company`）。
カード「緊急連絡先」: 氏名／電話番号／続柄（`emergency_name` `emergency_tel` `emergency_relation`）。
カード「備考」: `memo`（複数行テキスト）。

### STEP 2 保険・退職
- 加入保険情報: 健康保険番号・取得日（`health_no` `health_date`）／厚生年金（`pension_*`）／雇用保険（`employment_*`）／労災保険（`accident_*`）。
- 退職情報: 退職日（`retirement_date`）。ヒント「在籍中の場合は空欄のままにしてください」。**在籍状況トグルとは連動しない。**

### STEP 3 学歴・職歴・資格（行の追加・削除型）
| 区分 | 行の項目 |
|---|---|
| 学歴 | 卒業年月日（日付）／学校名／学科・専攻 |
| 職歴 | 年（4桁）／月（2桁）／会社名／部署／役職 ※備考の入力欄は**ない** |
| 免許・資格 | 資格・免許名／取得日 |
- 「＋ 追加」で空行を末尾に追加、「✕」で行削除。行数に上限なし。
- 編集時に既存行があれば復元される。

### STEP 4 扶養者
- 行: 氏名／フリガナ／続柄／生年月日。追加・削除は同様。

### STEP 5 確認
- JS生成の読み取り専用ビュー。表示項目は「基本情報」（社員コード・氏名・フリガナ・性別・生年月日・血液型・入社日・在籍状況）と「所属・役職」（所属・部署・役職・職種・雇用区分・週勤務日数・乗組員コード）のみ。未入力は「未入力」と表示。保険・退職・学歴・職歴・資格・扶養者・住所連絡先は表示しない。
- 編集時の乗組員コード表示は、新規入力欄が無いため既存の現行コードを表示。

### 保存の挙動 [コード確認]
- クライアントは入力値をまとめて `emp_employee_save` に送信（`id`=0で新規）。
- 成功: 「登録しました」／「更新しました」。失敗: サーバーのメッセージをトースト表示（`05` 参照）。
- 編集時、フォーム上の乗組員コードは**無視**される（`save()` は既存の現行コードを維持）。変更は履歴ブロック経由のみ。

## 3. マスタ管理（`#emp-master-page`）

- 上部タブ: 所属／部署／役職／職種（`data-type` = `affiliation` `department` `position` `job_type`）。タブ切替時に一覧を再取得。
- 各タブ:
  - 統計バッジ: 全件／有効／無効（検索前の全件ベース）。
  - ツールバー: 名称絞り込み入力（250ms遅延、クライアント側絞り込み）、「＋ 新規追加」。
  - テーブル: ID（`#id`）｜名称｜表示順｜状態（有効/無効のトグル表示）｜操作（編集・削除）。
  - インライン追加フォーム: 名称（最大100）＋表示順（数値、既定0）＋「登録」「キャンセル」。
- 動作:
  | 操作 | 動作 |
  |---|---|
  | 登録 | 名称必須。空なら「名称を入力してください」。成功で一覧再取得 |
  | 編集 | 名称セルが入力欄に変わり、Enter／フォーカスアウトで `emp_master_update`、Escで取消。**表示順の変更UIはない**（登録時のみ指定） |
  | 状態クリック | 有効⇔無効（`emp_master_update` の `is_active`） |
  | 削除 | `confirm()`→`emp_master_delete`。使用中は拒否 |
- 一覧は表示順→ID順。**無効な項目も表示される**。

## 4. CSV出力（`#emp-csv-page`）

構造は左（選択）と右（設定・実行）の2カラム。

左カラム:
- STEP 0 保存済みテンプレート（カード: 名前／列数／先頭4項目タグ＋「+N」。✏名前変更・✕削除。カードクリックで反映）。
- STEP 1 プリセット（基本情報のみ／人事用／保険情報／連絡先／すべて選択／クリア）。
- STEP 2 出力項目（グループ: 基本情報／所属・役職／連絡先／加入保険。グループごと「一括切替」＝全ON、全てONなら全OFF）。
- STEP 3 並び順（ドラッグ&ドロップ。番号・項目名・「✕」）。

右カラム:
- 絞り込み条件: 在籍状況、所属、部署、入社日（期間）。
- 出力設定: ファイル形式（CSV/TSV）、文字コード（Shift-JIS/UTF-8）、ヘッダー行（あり/なし）、ファイル名。
- 出力サマリー: 出力列数／ファイル形式（例「CSV / Shift-JIS」）／ヘッダー行、「CSV出力を実行」。

ダイアログ: テンプレート保存（名前、最大30文字）／テンプレート名変更。Enterで確定、Escで閉じる。

初期状態: 「社員コード・氏名・フリガナ・入社日・在籍区分」がチェック済み。

プリセット内容（`PRESETS`）:
| プリセット | 項目 |
|---|---|
| 基本情報のみ | employee_code, name, name_kana, hire_date, is_active |
| 人事用 | employee_code, name, name_kana, gender, birthdate, hire_date, affiliation_name, department_name, position_name, is_active |
| 保険情報 | employee_code, name, health_no, health_date, pension_no, pension_date, employment_no, employment_date, accident_no, accident_date |
| 連絡先 | employee_code, name, tel_mobile, tel_home, tel_company, emergency_name, emergency_tel, emergency_relation |
| すべて選択 | 全31項目 |
| クリア | なし |

出力実行: 非表示フォームを `admin-ajax.php` へPOSTし、ブラウザがファイルをダウンロード（`06` 参照）。

## 5. CSVインポート（`#emp-import-page`）

- 上部「インポート手順」カード（4手順）。
- タブ: ①基本情報／②経歴・資格／③扶養者（各 `.emp-import-panel`）。
- 各タブ共通:
  1. ひな形ダウンロードボタン（admin-ajax経由のGET、nonce付き）。
  2. ドロップゾーン（`.csv`のみ、ファイル選択も可）。
  3. 「重複社員コードの処理」ラジオ（スキップ／上書き更新）。**①のみ有効**（②③は選んでも追記）。
  4. 文字コード（自動/UTF-8、Shift-JIS）。
  5. 「プレビューを確認する」（ファイル読込後に有効化）。
- プレビュー: 件数サマリー「全 N 行 / エラー N 行 / 登録予定 N 行」、エラー行リスト、先頭数列のテーブル、「インポートを実行する」「キャンセル」。
- 結果: 新規登録／上書き更新／スキップ／エラー件数、エラー詳細、「社員一覧を確認する」リンク。
- クライアント側検証: 社員コード空、氏名空（①③のみ）を行単位で警告。サーバー側の検証が実際の判断基準。
- 既知の表示のずれ: ①のプレビュー表の見出し（13列）と値（12列）が1列ずれている（表示のみ。取り込みには影響しない）。`11` 参照。
- CSV解析はJS側（改行区切りで行を分割し、ダブルクォート・`""` に対応）。**セル内改行（クォート内の改行）は未対応。**
- 先頭BOM（U+FEFF）は除去される。

## 6. 共通UI部品
